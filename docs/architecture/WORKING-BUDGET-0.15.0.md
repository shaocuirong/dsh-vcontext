# v0.15 聊天工作预算

## 问题与修复

0.13–0.14的L1预算直接使用模型窗口减输出预留。正式宿主只读诊断观察到百万窗口、256000输出预留、158342输入，此时预算792576，压力19.98%，没有达到85%触发线；63页具备条件仍不会自动换出。空归档是未触发的结果，不能据此断言宿主不支持历史替换。

新增独立持久设置`l1_input_budget`，默认131072。`effective=min(configured, modelWindow-outputReserve)`；configured为0则跟随模型窗口。达到effective×high开始并滞回整理至effective×low；未解除任何来源、任务、最近内容、驻留和工具配对保护。超出工作预算可能是保护或每批限额的正常结果，不承诺每个会话都能达到低水位。

只在`va_state.config`补齐缺失键，保留已有关闭值与自定义预算，无新增表或主schema升级。数值必须为0–9e12整数，布尔值拒绝。仅本机同源宿主界面可配置；模型不能通过`auto_*`开启策略。默认更早整理为明确行为变化，可选择0恢复旧方式。

压力仍使用新鲜公开投影并覆盖系统提示、工具定义及注入内容。有效预算、模型输入上限、配置上限、模型窗口、输出预留和具体触发线分字段返回。不使用插件L2估算量代替请求压力。宿主原日志保留，合法Surface替换决定派生消息；下一真实请求的内容是独立验证层。

## 调度与界面

插件重载后枚举公开AgentRegistry.list()，观察已经附着的Agent。运行中的Agent仍等到idle；冷会话不被创建、唤醒或换出。每会话互斥、取消/卸载、30秒批次与失败退避保持原约定。

预算预设64/128/256 Ki及跟随窗口直接保存；L2容量预设只编辑草稿，保存时提交。高低水位按百分比联动，不允许停止线高于开始线；自定义容量保留精确整数。空归档直接说明未发生vctx历史换出；开启策略与执行结果分别展示。

完整回归和真实请求实验见[验证记录](../releases/VALIDATION.md)，原保护与回执约定见[自动整理](AUTOMATION-0.13.0.md)。

# v0.11.2：历史分页边界修复

1. 归属与隔离：沿替换链收集已知来源 turn/step，仅保护受影响 scope；未知替换自身隔离，阻止页面跨越它合并，不影响无关或后续页面。
2. 最近页保护：分段返回截断前 total_pages；planner 和 quota trial 按完整位置计算最近 N 页，max_pages 不改变旧页资格。
3. 连续换页：核验本会话 page-out 回执及原始来源、页面标识、字节和工具配对，避免自身 marker 阻止同一步骤/轮次后续换页；损坏回执仍保守保护。
4. 回归：整轮多 turn 归档后仍能分页；跨 step 嵌套替换保护残留源组且不污染其他 turn；6 页预览截断为 2 页仍可正常换出旧页；连续换出独立用户页及同一步骤 3 个工具组页面。

保留已有 v0.11.1 标签和预发布。升级后完全退出并重启 Harness；无数据库迁移或配置覆盖。

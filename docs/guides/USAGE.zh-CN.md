# 使用上下文工作台

1. 在输入框旁点击“上下文”，开启当前会话的工作台。也可先为新会话预选开关。
2. 在“实际上下文”查看窗口占用，点击分类展开页面。面积与单位以页面标注为准。
3. 在“虚拟上下文”筛选插件页面、历史来源或项目资源，点击方块读取固定版本内容与可用的历史版本。
4. 在左侧“设置”修改预算、水位、调度策略与展示偏好；浏览器偏好也可从宿主的“上下文展示”设置页进入。
5. 在“变化与调度 → 调度操作”先刷新预览，再归档历史或调整工具结果表示。宿主摘要可能调用模型；页面归档保留原始内容。
6. 在“变化与调度 → 来源恢复”搜索原始来源、读取摘要来源链，或保存带来源版本的笔记。
7. 在“变化与调度 → 活动状态”显式更新任务进度与下一步，管理上下文资源快照。报告完成不等于测试通过。

提交状态未知时先刷新核对，再显式重试相同操作；不要仅因响应丢失而换一个请求身份重复提交。新界面仍使用原后端的会话隔离、版本校验与保护规则。

图形、颜色、变化标签、覆盖范围与数据限制见 [界面说明](UI.md)。工具协议和所有后端参数见 [API](API.md)。旧发布版本的验证记录保留在版本化发布文档中，不作为新界面的验收结果。

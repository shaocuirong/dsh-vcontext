# 上下文工作台

v0.18.1 修复主题、内容阅读与布局问题。工作台跟随宿主颜色模式，使用紧凑顶部导航；宿主仍加载由源码构建的 `lib/client.js`。宿主中的入口名为“上下文工作台”，便于和原生上下文页区分。

## 窗口与页面

工作台采用三个顶部入口：上下文、变化与调度、设置，不再在宿主侧栏旁叠加内部侧栏。上下文使用单一空间画布与右侧内容检查器，最近变化收在底部摘要条。

窄容器使用原生模态底部抽屉，支持关闭、Escape 与浏览器焦点管理。抽屉进入浏览器顶层，避免容器查询的布局包含块把它定位到工作台底部而非视口。画布会根据实际宽高排布；太小的方块收起次要文字，完整名称仍可通过列表访问。

实际上下文先显示请求捕获时的宿主窗口估算：分类空间、已用量与剩余量。只有分类总量与容量口径可比较时绘制容量条。默认展开已用部分，让低占用时的分类也能阅读；独立容量条始终保留真实已用与剩余比例，可切回完整窗口。点击分类后，原画布切换成该分类的请求页图，并明确改用 JSON 字节计量；面包屑可返回总览。点击页面在检查器查看原文节选。请求页按用户消息开启的轮次组合，工具结果留在所属页。

请求目录最多128页，正文节选合计最多32768码点。超限内容仍计入总字节量。请求页以当前请求内位置标识，尚不能与所有持久历史页一一对应，因此变化标签明确写明按请求页位置比较。主请求的正常结束回执推进基准，失败和辅助调用不推进；它不是供应商费用证明。

![实际上下文](../images/workbench-actual.png)

虚拟上下文复用插件页面、归档历史、工具结果与已登记项目资源的权威目录。按来源字节切块，每屏20项；大小未知或为零的条目保留行列表入口。重复工具标题附来源序号，导航摘录仅用于辨识，不代替正文。颜色表示已观察的原文、引用、摘要，未知状态按来源使用中性色；颜色和已知变化状态分别表达。目录引用的成功交付不等于正文已注入。摘要属于来源的派生表示，不重复画成原始页面。

“内容变更”比较正文哈希；默认基准为最近正常结束主请求所观察的目录来源版本，也可手动保存当前查看基准。来源不在完整基准中时才标记“新收入”，覆盖不完整时保留未知。进程重启后没有交付观察时不推断过去的注入状态。

点击页可在检查器读取固定版本正文、摘要表示与可用的历史版本。每次读取最多4096码点，显示分段进度并使用返回的真实偏移继续。历史归档在工作台按角色、事件和消息正文作只读投影，独立于原始 JSON 的偏移；模型的 history_read、归档原文和数据库保持原样。未知消息块保留序列化内容，正文按文本渲染而非 HTML。历史来源可能记录访问计量，浏览不会换入页面。

完整引用和哈希折叠在“来源与完整标识”中，正文区域优先用于阅读。变化对比只有版本哈希时展示版本变化，不生成没有证据的文本差异。未登记文件、活动历史及有界扫描范围外的来源均保持覆盖未知。

## 参数与操作

- 展示偏好在宿主设置页，作用于当前浏览器，立即生效并自动保存；保存失败明确提示。
- 参数设置集中管理聊天预算、在线配额、水位、目录注入与自适应开关；提交前显示编辑值，当前配置另有只读详情。
- 命名空间工作页策略明确作用范围与下一次步骤检查的生效时间。
- 宿主挂载能力为只读状态，需要修改插件配置并重新加载。
- 调度与操作提供历史归档、工具结果外置/恢复、宿主摘要与插件工作页归档。
- 来源与恢复支持搜索、分页读取及带固定来源版本的笔记。
- 活动状态提供任务新建、显式进度更新及资源快照操作。
- 变化记录展示宿主回执；诊断展示计量、准入、供应商实际用量与覆盖范围。

未知提交结果不会自动重试；同一操作的显式重试复用请求身份。预算和水位写入以服务端校验为准。

## 源码与验收

`client/create-client.js` 负责宿主插槽；`dashboard.js` 组合三个入口；`runtime.js` 管理请求、偏好、查询与提交；`panels.js` 实现参数与操作；`workbench.js` 管理画布与读取状态；`canvas-view.js` 渲染同级画布与检查器；`tiles.js` 保证面积比例；`window-meter.js` 校验计量口径；`primitives.js` 与 `styles.js` 提供组件与隔离样式。

运行 `npm run build:client` 构建，`npm run check:client` 检查源码与产物一致。React 使用宿主实例。`npm run preview:dashboard` 启动本地隔离预览，使用合成内容、真实 SDK Surface 与临时数据库，没有供应商调用。

2026-10-31 验证：完整 Node 回归351项、Python 回归279项通过，均零失败、零跳过。通过 Edge 的浏览器连接检查深浅色、实际窗口、27项密集页面、分页、列表、正文阅读和窄屏模态抽屉。截图只使用隔离预览、合成内容与临时数据库；正式宿主重启与真实供应商调用另行验收。密集场景可设置 VCTX_PREVIEW_DENSE=1 后运行 preview:dashboard。

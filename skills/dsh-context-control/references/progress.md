# v0.18.1 当前实现范围

统一会话访问、控制调度和新 UI 已包含在本发布节点。这里记录维护范围；具体发行验证结果由仓库 docs/VALIDATION.md 维护，不继承早期节点的测试数量或未发布状态。

| 模块 | 当前能力 |
|---|---|
| 共享契约 | 原因词表、保护依据、独立预算与不可变计划 |
| 变更与版本 | 本会话工具效果、路径观察、Git/工作树/固定快照描述与依赖失效 |
| 统一目录 | page/resource、表示与来源、有界投影、成功交付基准与增量 |
| 写协调 | 维护仲裁、后台轮转、持久状态与不确定提交对账 |
| 恢复与准入 | 已知引用缓存、有界正文/展开、恢复额度和请求容量检查 |
| 阶段摘要 | 固定来源、原生证明、显式候选、独立语义评审与 CAS 激活 |
| 有界调优 | 目录收益/时延观察、有限配额和驻留窗口调整 |
| 工作台 | 圆角单画布、检查器、真实来源阅读、版本与变化、参数设置 |

后台自动生成器未启用；真实供应商费用、语义质量和正式宿主重启验收单独记录。部分来源、工作区与历史覆盖仍可能未知，不因 UI 或重构完成而扩大覆盖声明。

维护入口见 [契约](contract.md)、[维护路线](refactor-plan.md) 和 [验证方法](validation.md)。
